# 0.6.28

Released 2026-10-08. The compiler and every library move to 0.6.28 together. Nothing
that worked in 0.6.27 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.28) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.28 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.28` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.28` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.28` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.28` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.28` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.28` |
## New

- **Invitations by email.** `entity invitation invites member { project  email  role }`
  is an invitation to become a member by email. When someone opens the app signed in
  with it, a member is made from its fields of the same names, with the member's
  person the one signing in, and the invitation is deleted, in one transaction. From
  then on they're a member by who they are, so a later change of email changes
  nothing. Only a sign-in that vouches for its email takes one, whatever its capitals.
- **Steps done as someone signs in.** `on signin { each invitation where email ==
  me.email { ... }  delete each ... }` is done each time someone opens the app signed
  in, as them; `invites` is the usual reason, said whole.
- Everything in 0.6.27: what a page shows in its path, `find`, mentions and comments
  in an issue's history, a table's `only`, and `tint by`.
