# 0.15.1

Released 2026-10-15. The compiler and every library move to 0.15.1 together. A
terminal app started with agents that stop when it quits asks before it does.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.15.1) | one command, see [Install](/install) |
| The libraries desktop and terminal apps are built on | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.15.1) | installed with the compiler, in `~/.local/share/uione/0.15.1` |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.15.1 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.15.1` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.15.1` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.15.1` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.15.1` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.15.1` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.15.1` |

## Fixes

- **Quitting stops agents midway, so it asks first.** A terminal app started with
  `ONE_QUIT_STOPS_AGENTS=1`, as publish starts neotrac's beside its agents, asks
  before it quits while an agent is working on a card, naming each card and who
  holds it. q again quits, and Esc or Cancel goes back to the board. With nothing
  being worked on, q quits at once, as before.
