# 0.7.5

Released 2026-10-09. The compiler and every library move to 0.7.5 together. A page
with no title of its own leaves the breadcrumbs, as it leaves the heading.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.7.5) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.7.5 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.7.5` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.7.5` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.7.5` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.7.5` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.7.5` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.7.5` |
## Fixed

- **Breadcrumbs.** A page titled with just the site's name shows no heading, but it
  was still a crumb, named after the site, so pages under it read `uione › uione ›
  uione`. Such a page is no longer a crumb, and shows no trail of its own. It's
  decided by the title as written, so a project that shares the site's name keeps
  its place.
