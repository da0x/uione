# 0.6.11

Released 2026-10-07. The compiler and every library move to 0.6.11 together. Nothing
that worked in 0.6.10 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.11) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.11 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.11` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.11` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.11` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.11` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.11` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.11` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.11` |

## New

- **Row buttons on only some rows.** `delete "Remove" when person != me` puts a
  row's button only on the rows where its when holds, read from the row's own
  fields, like everyone's but your own. The checker holds the when to the fields
  the row has.
- **A row's when, outlined.** Each table column `@uione/compiler` outlines says the
  when it's written with, so an editor that changes the table keeps it.

- **Labels in color.** Each label has a color of its own, the same wherever it's
  shown, with the usual ones in the colors people expect, like red for a bug.
- **Denser pages.** Less room above a page's title, a table's search on the same row
  as its tabs, and tighter rows. Something written, like an issue's description,
  sits in a frame of its own, and a form for writing, like a comment, is as wide as
  its column.

## Fixed

- A table whose rows have different numbers of buttons keeps every row's cells in
  line.
- Copying a page writes a description under its own heading, named as the page
  names it, writes a choice as it's shown, like In progress, leaves out a person's
  id where their name is shown, and says a command that changed several fields at
  once, like starting an issue, once, as the page does.

## For a component set of your own

`Copy` takes `choices`, like `Table`'s. A `Table`'s `actions` may carry `when`, a function of the row: the row's buttons
are only those whose `when`, if any, holds for it.
