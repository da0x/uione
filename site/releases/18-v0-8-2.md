# 0.8.2

Released 2026-10-10. The compiler and every library move to 0.8.2 together. A
program on someone's computer, like an app's command, now signs in as them through
their browser.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.8.2) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.8.2 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.8.2` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.8.2` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.8.2` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.8.2` |

| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.8.2` |



## Programs sign in through the browser

- **`/authorize`.** Every app people sign in to has this page. A program on the
  person's computer opens it; they sign in as they always do and press
  **Authorize**, and the browser goes back to the program, which is signed in as
  them. **Cancel** tells the program no. It works with every way the app lets
  people sign in.
- **As native apps do with OAuth:** the program waits on `127.0.0.1`, and the code
  the page sends it is bound to a challenge only the program can answer. A code is
  good once, for five minutes, and only its hash is kept. See
  [the reference](/language/reference#a-program-signing-in-as-a-person).
- **In the C++ client:** `sign_in_with_browser(open)` does all of it, with `open`
  showing the address, as the `neotrac` command's `neotrac login` does.
- **Deploys:** an app people sign in to lets its backend sign these sign-ins as
  itself, as one with services already did.

```cpp
neotrac::client app({.server = "https://neotrac.org"});
app.sign_in_with_browser([](const std::string& url) { std::printf("Go to %s\n", url.c_str()); });
store(app.refresh_token());
```
