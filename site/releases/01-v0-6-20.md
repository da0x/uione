# 0.6.20

Released 2026-10-07. The compiler and every library move to 0.6.20 together. Nothing
that worked in 0.6.19 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.20) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.20 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.20` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.20` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.20` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.20` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.20` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.20` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.20` |

## New

- **A table hidden while it's empty.** `hide when empty` in a table's block leaves
  it out while it has no rows, like a person's reports on a front page they may
  never have used.
