# 0.7.0

Released 2026-10-08. The compiler and every library move to 0.7.0 together. A
project's files now say `import one`, uione's own library, which defines what a
project may say: `one upgrade` adds it, below the comments a file opens with, and
records the new version, so a project for 0.6.30 needs no edit by hand.

## New

- **uione's own library.** `import one` brings in `one`, written in uione and part
  of the compiler. It declares each setting a project block takes, with its type
  and what it's for, and the choices of each enum setting. A setting is checked by
  its type: `corners square`, or in full, `corners one::corners::square`; a domain,
  slug, version, color, file, folder, address or link is checked as one. A name
  the library doesn't define isn't a setting, and the checker lists the ones there
  are. Hovering over a setting says what the library says of it.
- **Settings offered as they're typed.** The editor offers a project's settings in
  its block, each with its type and what it's for, an environment's in its block,
  and an enum setting's choices after its name. `@uione/compiler` has `complete`
  for it, and `@uione/editor` a CodeMirror source, `completions`.
- **Colors for a section or a filter.** `section "Wiki" color violet { ... }` draws
  a section's heading, links and tables in its color, and `filter "High priority"
  priority == priority::high color red` draws a card's filter as a chip of it. The
  colors are the library's `hue`: blue, teal, green, amber, red and violet, each
  in the component set's own shade, light and dark.
- **Opening light or dark.** `appearance light`, or `dark`, opens a site in it from
  the first paint, whatever the visitor's system prefers. A visitor's own pick with
  the toggle still wins.
- **Closer rows.** A table's rows sit a little closer, and its toolbar has a button
  for compact rows, which every table on the site follows once a reader picks it.
