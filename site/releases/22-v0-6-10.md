# 0.6.10

Released 2026-10-06. The compiler and every library move to 0.6.10 together. Nothing
that worked in 0.6.9 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.10) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.10 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.10` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.10` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.10` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.10` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.10` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.10` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.10` |

## New

- **Row buttons named, and only for those allowed.** `delete "Remove"` in a table's
  block names the button on each row, and like any other button it's there only
  for someone whose role lets them press it.
- **Screens and tables, outlined.** Checking a project with `@uione/compiler` also
  says where each screen's layout, regions and items are written, and each table's
  columns and settings, so an editor can lay a screen out by pointing and change
  just those lines.

## Fixed

- A `::delete` command's body now runs before it deletes. It was skipped, so a
  `require` in it, like never removing yourself from a project, didn't hold.
- The editor colors only `.one` files with uione's words; a `.tsx` or a README
  gets the theme's colors and nothing else.
- A site whose components use `@uione/compiler` can check code under Vite's
  development server, which left the compiler's worker behind.

## For a component set of your own

A `Table`'s `actions` may be `{ name, label, allowed }` as well as a command's name.
