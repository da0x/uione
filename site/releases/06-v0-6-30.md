# 0.6.30

Released 2026-10-08. The compiler and every library move to 0.6.30 together. Nothing
that worked in 0.6.29 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.30) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.30 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.30` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.30` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.30` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.30` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.30` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.30` |
## New

- **What a site is by, and built from.** `copyright "Ada Lovelace"
  "https://www.linkedin.com/in/ada"` puts "© 2026 Ada Lovelace" at the foot of every
  page, the name linked when a link is given. Beside it are the uione release the
  site was built with and the commit it was built from, so what's deployed can be
  told at a glance. The deploy builds the web app with the commit, as git says, or
  as `UIONE_COMMIT` does when a deploy names it.
- uione.io has an About page.
