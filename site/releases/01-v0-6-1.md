# 0.6.1

Released 2026-10-05. The compiler and every library move to 0.6.1 together. Nothing
that worked in 0.6.0 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.1) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.1 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.1` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.1` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.1` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.1` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.1` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.1` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.1` |

## New

- **The editor fills the window.** A button in the workbench's top right corner
  makes it full screen, over the page, and the same button, its arrows turned in,
  or Escape, puts it back.
- **On a phone, tapping the code goes full screen first.** The page no longer
  zooms in on the code and opens the keyboard over it; the code fills the screen,
  large enough that typing doesn't zoom it either, and a second tap edits.

## Fixed

- **The theme's button is its preview,** to the button's own border, with no
  second box inside it.
- **The theme gallery has no heading.** The previews say which they are; on a
  phone its title is Themes.
