# 0.6.14

Released 2026-10-07. The compiler and every library move to 0.6.14 together. Nothing
that worked in 0.6.13 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.14) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.14 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.14` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.14` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.14` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.14` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.14` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.14` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.14` |

## New

- **Presets a project starts from.** A command says `if workflow == workflow::kanban
  { ... }`, so a project makes the phases, steps and roles of the preset it picks.
  In a `create`, or an assignment like `start = phase::to_do`, `phase::to_do` is the
  project's own phase of that name, and a list field takes its values whole:
  `roles = [role::maintainer, role::member]`.
- **Order by what rows point at.** A list orders by a field of what each row points
  at, like a step's `from.position`, when it shows that field.
- **Work a deploy does once.** `one.Once` in Go written by hand does work the first
  time a backend with it starts, and never again, like moving what's stored to a new
  shape; `Module.Add` puts it in a namespace, and `one.FetchAll` reads every entity
  of a kind.
