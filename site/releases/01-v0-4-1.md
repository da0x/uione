# 0.4.1

Released 2026-10-04. The compiler and every library move to 0.4.1 together. Nothing
in the language changes, so a project for 0.4.0 needs no edit: `one upgrade` records
the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.4.1) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.4.1 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.4.1` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.4.1` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.4.1` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.4.1` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.4.1` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.4.1` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.4.1` |

## New

- **The editor's controls in an app's own bar.** `LookControls` are the text's size,
  as a large and a small A, the font, the tab width and the legend, for an app to put
  in a bar it already has; `useLook` keeps the reader's choices, and a `Workbench`
  given a `look` shows no toolbar of its own.
- **The legend links to the reference.** Each kind of word opens the section that
  says what it is, and the reference has new sections for what had none:
  declarations, comments, strings, numbers and operators, built-in values,
  keywords and field rules.
