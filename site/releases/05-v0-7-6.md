# 0.7.6

Released 2026-10-09. The compiler and every library move to 0.7.6 together. A
command that makes many records answers in a fraction of the time, and everything
that opens over a page fills the screen on a phone.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.7.6) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.7.6 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.7.6` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.7.6` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.7.6` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.7.6` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.7.6` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.7.6` |
## Fixed

- **Faster commands.** Views were rebuilt once for each record a command changed,
  one after another, before it answered. Making a neotrac project, with its roles,
  board, phases and steps, rebuilt the project's page some 25 times: 29 seconds. A
  command's changes now rebuild each page they touch once, several pages at a time.
- **Dialogs on a phone.** Dialogs and the display settings open the same way: in
  the middle of a wide screen, and the whole screen on a phone, with the title and
  × held at the top, above the page's header. The display settings had run off the
  side of a phone's screen, and a tall dialog had opened under the header.
- **Focus after a dialog.** Closing one gives focus back to the button that opened
  it.
