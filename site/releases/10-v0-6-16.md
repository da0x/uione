# 0.6.16

Released 2026-10-07. The compiler and every library move to 0.6.16 together. Nothing
that worked in 0.6.15 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.16) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.16 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.16` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.16` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.16` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.16` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.16` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.16` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.16` |

## New

- **Workflows edited on the page.** Everything a project needs to let its people
  change its own workflow without a deploy:
  - A row's button for a command with a `form` on the screen opens that form,
    started from the row: `update "Rename"` with `form phase::update { title }`.
  - `grid project_page.steps by from and to over project_page.phases { roles.title }`
    draws what goes between two of a list's things, a row and a column for each;
    an empty cell opens the create form with both filled in, a full one the update
    form with Remove beside it. Grid is a new primitive of the component contract.
  - `reorder position` lets a table's rows be dragged into order, or moved with
    Alt+↑ and Alt+↓, for whoever may update them.
  - `name text required key = slug(title)` makes a key from a title when none is
    given, and refuses a second whose title makes the same one.
- **Commands that do more in one step.** `input into phase` is sent with a command
  and never stored, asked for by its forms. `each issue where phase == id { ... }`
  changes other entities in the command's step, and `delete each step where from ==
  id || to == id` deletes them, each with its history. A delete's body is now saved
  with it.
- **Clearer pages.** A step names where it is when no step of the person's roles
  leads on, like No moves from Done for your roles. One of a list's records is
  picked from a drop-down however few there are. A radix row's buttons are named for
  their row, like Rename Open.
