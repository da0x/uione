# 0.5.3

Released 2026-10-04. The compiler and every library move to 0.5.3 together. Nothing
in the language changes, so a project for 0.5.2 needs no edit: `one upgrade` records
the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.3) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.3 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.3` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.3` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.3` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.3` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.3` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.3` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.3` |

## Fixed

- **A fresh project's first deploy.** Turning an API on returns before Google has
  spread the word, so the first deploy into a new Google Cloud project imported its
  Firebase Hosting site seconds after turning the Hosting API on, and Google refused
  it as not on yet. A deploy now waits until Firebase Hosting answers for the
  project, which it does at once when its API was on already.
