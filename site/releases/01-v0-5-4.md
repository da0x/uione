# 0.5.4

Released 2026-10-05. The compiler and every library move to 0.5.4 together. A
project for 0.5.3 needs no edit: `one upgrade` records the new version. Two
environments in one Google Cloud project are an error now, since they'd deploy over
each other.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.4) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.4 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.4` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.4` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.4` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.4` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.4` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.4` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.4` |

## New

- **What a name means, on hover.** Resting the pointer on a name in the editor says
  what it is, like "field takes_reports of project, a boolean", and where it's
  declared; Ctrl or Cmd and a click, or F12, goes there, and one of the language's
  own words, like `signed_in`, opens its section of the reference.
  `@uione/compiler`'s `define` answers for any line and column.
- **A command can name its entity's fields with the entity's name.** In a command on
  report, `report.project.takes_reports` means the same as `project.takes_reports`,
  for when a field is named for its type.
- **Names and scope**, a new section of the [reference](/language/reference#names-and-scope),
  says what's in scope in an entity, a command and a view, and why nothing is
  imported.

## Fixed

- **Renaming an environment keeps its stack.** An environment's Pulumi stack was
  its name, so renaming it made a new, empty stack that tried to make everything
  again. Its stack is its Google Cloud project now, and a deploy takes over the stack
  that already holds that project, renaming it, so projects deployed before carry on.
- **What can't be done yet is said in its own file**, rather than the first file of
  its namespace.
