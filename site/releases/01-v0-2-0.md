# 0.2.0

Released 2026-10-02. The compiler and every library move to 0.2.0 together.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler | [github.com/da0x/uione](https://github.com/da0x/uione), tag `v0.2.0` | built from source, see [Start](/language/start) |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.2.0` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.2.0` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.2.0` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.2.0` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.2.0` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.2.0` |

## Changes that need an edit

- **A link says where it goes before its text**: `link /docs "Read the docs"`, not
  `link "Read the docs" /docs`. The old order is an error that says what's expected.
- **A link has to reach a screen that's there.** A link to an address that no screen
  has, like a typo, is an error rather than a page that isn't found.

## New

- **Deploy from anywhere.** A project with a `project` block gets `build/deploy`
  wherever it is, built on the released `infrastructure` library, rather than only
  inside a clone of this repository. The deploy is one Go program: Pulumi through
  its Automation API, then the web app straight to Firebase Hosting.
- **`link namespace projects "See the projects"`** opens a namespace's own screen,
  so a renamed namespace is caught by the compiler.
- **Readers named by a field.** `readers report.author` lets whoever filed a report
  read it, even outside the project, and a list of people works too, like
  `readers report.watchers`.
- **`component name`** draws a hand-written React component on a screen, for
  anything the language doesn't say.
- **Table links fill earlier parameters** from the screen's address, or from the row
  when it holds them: a list of one person's issues across projects links each to
  `/projects/:project/issues/:issue`.

## Fixed

- Two entities whose fields share a name and a choice, like an issue's and a
  report's `status: open`, no longer generate the same Go constant. Each is named for
  its entity: `IssueStatusOpen` and `ReportStatusOpen`.
