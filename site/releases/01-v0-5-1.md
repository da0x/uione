# 0.5.1

Released 2026-10-04. The compiler and every library move to 0.5.1 together. Nothing
in the language changes, so a project for 0.5.0 needs no edit: `one upgrade` records
the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.1) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.1 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.1` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.1` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.1` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.1` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.1` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.1` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.1` |

## Fixed

- **Names after `::` are names.** In a role block, a line starting with
  `project::update` was highlighted as a project declaration naming `update`, and
  the `create` in `member::create` as a keyword. A declaration's word before `::` is
  a qualifier now, and the word after it a name, in the editor, on this site, and in
  Vim and VS Code.
- **`one upgrade` lines up the enums it writes.** Their choices start in the column
  the other fields' rules do, as in `role     enum     maintainer | reporter`, and
  the examples and the reference are written that way.
