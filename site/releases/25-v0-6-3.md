# 0.6.3

Released 2026-10-05. The compiler and every library move to 0.6.3 together. Nothing
that worked in 0.6.2 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.3) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.3 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.3` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.3` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.3` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.3` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.3` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.3` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.3` |

## Fixed

- **The theme's button lines up with the rest.** It sat a few pixels lower than the
  toolbar's other controls; each control is now centered in the toolbar.

## Also in this release

0.6.1 and 0.6.2 weren't published to npm, so their changes reach npm with this
release: GitHub sign-in asks for the person's email, so one kept private still
finds their account; the editor fills the window from its corner; a tap on the
code on a phone goes full screen first; and the theme's button is its preview.
