# 0.6.7

Released 2026-10-06. The compiler and every library move to 0.6.7 together. Nothing
that worked in 0.6.6 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.7) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.7 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.7` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.7` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.7` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.7` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.7` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.7` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.7` |

## New

- **A view shows a field of what it points at.** `lifecycle =
  issue.project.lifecycle` puts the issue's project's lifecycle on every issue's
  page, and changing the project changes it on each of them.

## Fixed

- **What a view can't do yet is said in its own file.** Such an error named
  whichever file was read last, with the view's line number.

## Also in this release

0.6.6 may not be published to npm yet; if it isn't, its changes reach npm with this
release: the copy button, buttons that ask about `me`, and changes said as what
their command did.
