# 0.5.2

Released 2026-10-04. The compiler and every library move to 0.5.2 together. Nothing
in the language changes, so a project for 0.5.1 needs no edit: `one upgrade` records
the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.2) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.2 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.2` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.2` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.2` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.2` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.2` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.2` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.2` |

## Fixed

- **A field given a value is a name.** In `create member { project = id }`,
  `project` was highlighted as a project declaration. A declaration's word followed
  by `=` is a field being given a value now, in the editor, on this site, and in Vim
  and VS Code.
