# 0.5.0

Released 2026-10-04. The compiler and every library move to 0.5.0 together. Nothing
that worked in 0.4.1 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.0) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.0 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.0` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.0` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.0` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.0` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.0` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.0` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.0` |

## New

- **Environments.** A project can run in more than one place, each deployed on its
  own: `environment staging { domain firebase region }` in the project block holds
  what's that place's own, and settings outside the environments are shared. `one
  build --for staging` builds for one, and its deploy uses the Pulumi stack named
  after it; without `--for`, a project is built for its first environment. See
  [environment](/language/reference#environment).
- **The project block's outline.** `@uione/compiler`'s check says where the project
  block's settings and environments are, line by line, for an editor that adds or
  removes them; its build takes the environment to build for.

## Fixed

- **The editor reports only typing.** A file's text arriving was reported as a
  change, as though someone had typed it.
