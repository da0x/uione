# 0.10.1

Released 2026-10-12. The compiler and every library move to 0.10.1 together. Two
fixes found by running neotrac's generated apps end to end on the emulators.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.10.1) | one command, see [Install](/install) |
| The libraries desktop and terminal apps are built on | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.10.1) | installed with the compiler, in `~/.local/share/uione/0.10.1` |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.10.1 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.10.1` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.10.1` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.10.1` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.10.1` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.10.1` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.10.1` |

## Fixes

- **Whoever may take a step out of a stage works it.** A workflow's stage allows
  claiming to the roles it lists, and now also to the roles of any step out of it,
  since whoever can move an issue from a stage can work on it there. For stages
  written in the code, those roles find the stage's issues in their queue too.
- **Native forms leave file fields out.** A form with an attachments field sent it
  empty, as text, from the desktop and terminal apps, and the command turned the
  form down. Now nothing is sent for file fields, so what's attached stays, and the
  form says files are attached on the web.
