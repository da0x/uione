# 0.7.1

Released 2026-10-08. The compiler and every library move to 0.7.1 together. Who a
site is by is no longer a setting: `one upgrade` moves a project's `copyright` into
a footer below its project block, with what the site was built from, and records
the new version, so a project for 0.7.0 needs no edit by hand.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.7.1) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.7.1 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.7.1` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.7.1` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.7.1` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.7.1` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.7.1` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.7.1` |
## New

- **A footer, declared like a screen.** `footer { ... }` is drawn at the foot of
  every page with text, links and sections of them, in one quiet line, or with
  `footer columns`, a column for each section. A site has one, or none.
- **What a site was built from, said and linked.** Text can say `{year}`,
  `{build.version}` and `{build.commit}`. `link build.release` opens the uione
  release notes on GitHub, and `link build.source` the commit in the site's own
  repository, which the deploy finds from git, or from `UIONE_REPOSITORY`.
- **Links in words.** Text links words as Markdown does: `[Ada Lovelace](https://...)`.
- **A color for a table.** `color violet` in a table's block draws its rows' links in
  it, while the section around it keeps the page's own heading and links.
- **Diagrams sit centered**, with what to do under them.
