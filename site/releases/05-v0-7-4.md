# 0.7.4

Released 2026-10-09. The compiler and every library move to 0.7.4 together. The
browser compiler can show a project's themes to a designer and says how a mistake is
fixed, the editor colors the newest words, and deploys bring a site's packages up to
date.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.7.4) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.7.4 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.7.4` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.7.4` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.7.4` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.7.4` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.7.4` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.7.4` |
## New

- **Themes for a designer.** The browser compiler's `themes` lists a project's
  themes: what each says itself, what it takes from the theme it starts from, and the
  colors it's drawn with, light and dark. The studio's Theme tab is built on it.
- **Fixes with problems.** A problem with one answer, like a color that doesn't read,
  carries its fix: where it goes and what it says.

## Fixed

- **Highlighting.** In `board::create`, `board` is no longer colored as a keyword,
  the scope after `define role … in` has the entity color, and `accessibility` is a
  setting.
- **Deploys bring packages up to date.** A site deployed from a folder built before
  kept the web packages that build installed. A deploy now always installs first.
