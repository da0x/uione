## Changes that need an edit

`one upgrade` makes these edits for you: it brings a project to 0.4.0, applying
each fix the compiler knows, and records the version in the project block. What it
can't fix, it lists, and changes nothing until you have.

- **Choices are an enum, and each choice is named with it.** A field of choices
  says `enum`, and a choice is written with its enum's name wherever it's used:
  ```one
  status  enum open | closed = status::open

  command issue::close {
  	require status == status::open  "that issue is already closed"
  	status = status::closed
  }
  ```
  That's in starting values, commands, comparisons, a view's `public when` and
  `where`, and what a command creates. The code a project becomes doesn't change.
- **A role is declared once.** Two `role maintainer` lines used to keep only the
  second one's permissions; now it's an error. A role with many permissions lists
  them in a block, below.
- **A project that names no way of signing in offers none.** A project block
  without `signin` no longer shows a Sign in button. To keep it, say how people
  sign in: `signin google`.

## New

- **A project names its compiler**: `one "0.4.0"` in the project block, the last
  version it was checked clean with. Any `one` hands a project to the version it
  names, fetching that release once and checking it against the release's
  checksums, so a project builds with the compiler it was written for, everywhere,
  deploys included. `one upgrade` moves it to a newer one, fixes first.
- **Sign in with GitHub**: `signin github`, keeping each person's GitHub username
  on their profile.
- **Addresses named by keys.** `namespace studio at /` puts a namespace's screens
  at another address, and an entity keyed by its owner's username and a slug is
  found at `/:owner/:project`, as GitHub names repositories. A field can start as
  `= me.username`.
- **The `slug` type**: a name like `my-app`, lowercase letters and digits joined by
  single dashes, lowered as it's saved.
- **Choices with labels**, `license  enum mit "MIT" | apache_2_0 "Apache-2.0"`,
  picked from cards when there are a few and from a list when there are more,
  starting on the field's default.
- **A role's permissions in a block**, as many to a line as reads well:
  ```one
  role maintainer per project from member {
  	project::update  member::create
  	issue::create  issue::update  issue::close  issue::reopen
  }
  ```
- **`menu`**: links down the side of a screen, with the rest of it beside them, the
  one for the page it's on marked.
- **An address that takes the rest of it**: `/code/:file*` is at
  `/code/components/chart.tsx`, and moving between such addresses keeps the page.
  Addresses can name files, with a dot.
- **`title "uione"`** in a project names it at the top of every page, when the
  project's own name is for what it runs on.
- **`redirect "/from" "https://..."`** sends an address that has moved on, and a
  link can go to another site: `link "https://..." "text"`.
- **A form names its button**: `form project::update "Save changes" { ... }`, also
  for a form behind a button and its dialog.
- **Hand-written components share code.** Every `.ts`, `.tsx` and `.css` file in
  `components/` comes into the app, so components can import a module of their own.
- **`s.SignedIn(r)`** tells a route in a backend who sent its request.
- **The editor**, `@uione/editor`:
  - line numbers, undo and the usual key bindings, highlighting in dark mode;
  - a read-only mode, and a mode without the generated code;
  - `Diff`, what changed in a file, on CodeMirror's merge view;
  - going to a place an address names, as GitHub's do, `#L12C5` or `#L12-L20`,
    with its lines marked, and saying where the cursor moves.
- **A sharper look** for `@uione/radix`: IBM Plex, an exact cool palette, a sticky
  header, a light and dark toggle, and pages as wide as the window, with text
  keeping its own reading width.
