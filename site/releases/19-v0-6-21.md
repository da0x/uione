# 0.6.21

Released 2026-10-07. The compiler and every library move to 0.6.21 together. Nothing
that worked in 0.6.20 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.21) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.21 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.21` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.21` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.21` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.21` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.21` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.21` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.21` |

## New

- **People picked from the project's own.** A form's field holding a person, or a
  list of people, like an issue's assignees, picks from a list on the screen whose
  rows hold a person and their name, like a project's members, each person once.
- **Names through a list of people.** A view reads names, pictures and usernames
  through a list of people too, like `assigned = issue.assignees.name`.
- **Adding to a list by name.** `add milestone::create to may` adds a command a role
  allows, or one of a project's own by its name.

## Changed

- PaperColor's accent is its blue, #005faf, rather than a dark cyan.
- A change of something long, like a wiki page's text, says only that it changed.

## Fixed

- A date picked without a time shows, and fills a form, as that day wherever the
  reader is, not the evening before.
- A card's count of one names it in the singular, like 1 issue.
