# 0.6.23

Released 2026-10-08. The compiler and every library move to 0.6.23 together. Nothing
that worked in 0.6.22 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.23) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.23 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.23` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.23` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.23` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.23` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.23` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.23` |
## New

- **Tables and boards on a phone.** On a page narrower than a tablet, a table lists
  each row as one entry, its title across the whole width with a number like #12
  before it, and its other columns on a line under it, leaving out the empty ones.
  A board shows one phase a page, swiped between or picked from tabs with their
  counts, and a card that can move has a Move to picker, since a finger can't drag
  it. Wider pages are as they were.

## Changed

- A copy button holds the lists its screen shows, and leaves out a list only its
  buttons go by, like the steps an issue's Move buttons follow.
