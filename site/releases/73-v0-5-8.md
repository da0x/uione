# 0.5.8

Released 2026-10-05. The compiler and every library move to 0.5.8 together. Nothing
that worked in 0.5.7 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.8) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.8 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.8` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.8` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.8` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.8` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.8` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.8` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.8` |

## Fixed

- **Forms ask someone signed out to sign in.** A form for a command that needs its
  person signed in, which is every command but one `anyone` may run, was shown to
  everyone, and refused only once sent. Now someone signed out sees Sign in to ...
  in its place, which signs them in and then shows the form.
- **What's refused to someone signed out isn't drawn for them.** A table of their
  own things, like the projects they're in, said "You can't see this" to visitors;
  now it's left out until they sign in.
