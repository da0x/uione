# 0.6.6

Released 2026-10-06. The compiler and every library move to 0.6.6 together. Nothing
that worked in 0.6.5 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.6) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.6 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.6` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.6` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.6` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.6` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.6` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.6` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.6` |

## New

- **Copy a page whole.** `copy issue_page "Copy issue"` is a button that puts
  everything the view holds on the clipboard as Markdown: the page's title, its
  values, a description as it was written, the conversation as who wrote what and
  when, and the changes as what happened. As the view gains fields, so does what it
  copies.
- **Buttons about whoever is reading.** A button's `when` can say `me` and `has`:
  `issue::take "Assign to me" when !(issue_page.assignees has me)`.
- **A change says what its command did.** With `action` in a timeline's rows, a
  change made by a command of its own, like closing an issue, reads "Ada closed this"
  rather than which field changed.
