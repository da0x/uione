# 0.6.8

Released 2026-10-06. The compiler and every library move to 0.6.8 together. Nothing
that worked in 0.6.7 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.8) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.8 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.8` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.8` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.8` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.8` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.8` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.8` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.8` |

## New

- **A site's own color.** `color "#0f766e"` in the project block draws its buttons,
  links and focus rings in that color, and a lighter one of it on a dark page. The
  checker makes sure it's dark enough to read as a link on a white page.
- **A timeline of many things.** `timeline project_page.timeline link
  /:project/issues/:issue` lists every change to a project's issues, each naming
  the issue it was to, by the list's own columns, like `issue.number` and
  `issue.title`, and linking to it: "Ada closed #12 Copy an issue whole".
- **A field called what it is.** `form comment::create "Comment" { body "Comment" }`
  labels a field other than by its name.
- **Links side by side.** Links one after another on a screen sit in a row, as
  buttons do.

## Fixed

- **Nothing written takes no room.** An empty description, or a conversation not yet
  begun, no longer leaves a gap or says "Nothing here yet".
- **A Markdown field is named for screen readers.** Its text box is labelled by the
  field's label.
