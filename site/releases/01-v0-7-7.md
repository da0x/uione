# 0.7.7

Released 2026-10-10. The compiler and every library move to 0.7.7 together. Long
conditions go one a line, a value picked by a choice is one `match`, and a button
carries its form. `one upgrade` makes the changes that have one answer.

|---|---|---|

| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.7.7 check .` |

## Shorter commands

- **Conditions one a line.** `where`, `public when` and `require` take a block of
  conditions, as `when` does: every line holds, and a line can still use `||`.
  `require` puts its message first:

  ```one
  require "your role doesn't move an issue from there to there" {
  	exists(step where from == was issue.phase && to == issue.phase && held(roles))
  }
  ```
- **`match`.** A value picked by a choice of an enum, a line for each choice, and
  `else` for the rest. Every choice is said or there's an `else`, so a choice added
  later is an error until each match says what it gives. neotrac's seven `if`
  blocks for a link's other side are one:

  ```one
  relation = match relation {
  	blocks      blocked_by
  	blocked_by  blocks
  	relates     relates
  }
  ```
- **A button with its form.** `issue::update "Edit" form "Save" { title  body }` is
  the button and the form it opens. `one upgrade` joins a form to the button just
  above it.
- **`each other`.** An `each` over the command's own kind names its rows `other`:
  `each other link where other.pair == id || other.id == pair`, so a bare `pair` is
  always this link's. `one upgrade` names it.

## Fixed

- **A permission names a command, or `view`.** `role librarian book::read` was
  accepted because `book` is an entity. It's now an error that says what a
  permission can be.
