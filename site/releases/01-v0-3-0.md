# 0.3.0

Released 2026-10-02. The compiler and every library move to 0.3.0 together.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.3.0) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.3.0 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.3.0` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.3.0` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.3.0` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.3.0` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.3.0` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.3.0` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.3.0` |

## Changes that need an edit

- **A link's address is inside its namespace**, like a screen's. In `namespace
  projects`, `link /:project/reports "Reports"` goes to
  `/projects/:project/reports`. A link inside a namespace that wrote the whole
  address, like `/projects/archive`, now writes `/archive`, and a link to another
  namespace names it: `link namespace docs "Read the docs"`. Links outside every
  namespace are unchanged.

## New

- **A link's `:parameters` come from the page it's on**: on `/projects/uione`,
  `link /:project/reports "Reports"` goes to `/projects/uione/reports`. The page
  has to have each one, or the compiler says which is missing.
- **Go written by hand.** `backend deploy` in a namespace builds
  `backend/deploy.go` into its package, the way `component` draws React. It can run
  code `After` a command's change is saved, answer requests of its own with
  `one.Route`, run any command as the backend itself, and read what's stored with
  `one.Fetch` and `one.FetchWhere`.
- **Firebase is part of the deploy.** A Google Cloud project gets Firebase added by
  its Pulumi program, so a fresh project needs no trip to the Firebase console for
  it. A project that has Firebase already keeps it.
- **Deploy with nothing installed.** `ghcr.io/da0x/uione-builder` holds `one`, Go,
  Node, Yarn, Pulumi and gcloud, and a deploy installs the web app's packages
  itself when they aren't there. It's what the studio deploys projects in.

## Fixed

- A view can read through who made or last changed something, as
  `created_by.name`. The compiler allowed it, but the backend stopped at its start
  when a view did.
