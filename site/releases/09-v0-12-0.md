# 0.12.0

Released 2026-10-13. The compiler and every library move to 0.12.0 together. Agents
work a workflow's stages as programs of their own; boards show how each card is
going, with a colored dot, who's on it and for how long; columns chime; desktop
boards are dragged; and a record's page can stay private inside a public container.

## New

- **Agents.** `define agent press for printer { on plate in etching run "./etch"
  then etched else spoiled }` is a program of its own, built with the app: it signs
  in with a service's key, takes what arrives in the stages it works, runs the
  program with the record as JSON on its input, keeps its lease while it runs, and
  moves it on, or to `else` when the program fails. Several agents, or several
  processes on one key, share the work: the least busy one usually asks first, and
  none ever runs a card another holds. Asked to slow down, an agent waits and asks
  again, so a burst of cards is each worked once. `examples/print_shop` shows it.
- **Flows that wait on each other.** `depends on packages` in a workflow keeps a
  record from moving on until what it names is `done at` its last stage, and
  `waiting(packages)` in a require says which it's still waiting on.
- **A card shows how it's going,** in the web, desktop and terminal apps: a dot,
  gray when it hasn't started, orange while it's worked, blue while it waits, green
  when it's done and red when it failed, with the runner on it and a time that
  counts up. A workflow's records carry `data`, named values its holder reports
  with `<entity>::report`; `data.status` and `data.since` are what the dot and the
  time read, and a live lease shows as working by itself.
- **Columns that chime.** A stage that says `notify chime` rings when a card
  arrives in it, in every app. A board over stage records says which of their
  fields decide it: `chime when notify has chime` and `status by status`.
- **Boards of stages written in the code**, as an enum, have their columns and
  steps from the workflow.
- **Drag and drop on the desktop.** A card is dragged to a column a step leads to;
  the others dim while it's carried.
- **`public when` holds several conditions, through any pointers.** A record's page
  is public only while every line holds, like a board's own visibility and its
  project's, and closes as soon as one doesn't.
- **Desktop and terminal apps sign in with `ONE_KEY`,** a service's key, even when
  the app has no sign-in of its own.

## Fixes

- **A private record's files** were readable through a public page of what it
  points at. A record's own page now decides, and only one with no page of its own
  falls back to what it points at.
- **A list hidden while it's empty** is hidden too from whoever can't read it,
  rather than showing an error.
- **A view inherits its readers from two containers,** holding both their
  conditions, rather than giving up.
- **A command reads a field two records away,** like `from.board.visibility`, and a
  command named like an entity no longer clashes with it.
- **A claim waits for any live lease,** so two holders never share a record.
