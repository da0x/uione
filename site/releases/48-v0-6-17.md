# 0.6.17

Released 2026-10-07. The compiler and every library move to 0.6.17 together. Nothing
that worked in 0.6.16 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.17) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.17 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.17` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.17` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.17` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.17` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.17` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.17` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.17` |

## New

- **A board of cards.** `board project_page.issues by phase over project_page.phases`
  shows a list's rows as cards in a column for each phase, in order, with how many
  each holds; its block says what a card shows, title first, and `link` opens a
  card's page.
- **Cards moved along steps.** With `move issue::move along project_page.steps` in
  its block, a card is dragged, or moved with Alt+← and Alt+→, to a column a step
  from its own leads to for one of the person's roles. The columns it can't go to
  are dimmed while it's dragged, and it shows in its new column at once, going back
  if the move fails.
- **A table or a board.** A table and a board of the same list, one right after the
  other, are one switch, and each person's pick is remembered. Board and Switch are
  primitives of the component contract.
