# 0.14.2

Released 2026-10-14. The compiler and every library move to 0.14.2 together. A
deploy starts the new backend on a copy of what's stored before it changes
anything, builds the backend's image in seconds rather than minutes, and says
why when Cloud Run turns a backend down.

|---|---|---|

| The libraries desktop and terminal apps are built on | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.14.2) | installed with the compiler, in `~/.local/share/uione/0.14.2` |

## New

- **A deploy rehearses the backend before it changes anything.** Once Pulumi has
  shown what it will do, the new backend is started on a Firestore emulator in
  Docker holding a copy of what the project stores, its views left out, and
  nothing is built or changed until it starts. What it does as it starts, like a
  `once` moving records along, fails here in seconds, saying what the backend
  said, rather than in Cloud Run once its image is built. It reads what's stored
  and writes only to the emulator, which goes when it's done. Where there's no
  Docker, the deploy says so and goes on.
- **The backend's image is built in seconds.** The backend is compiled where the
  deploy runs, with Go's own caches, and Cloud Build only puts the binary in an
  image, rather than downloading and compiling every module again each time.

## Fixes

- **A backend Cloud Run turns down** is explained by its revision's log: the
  deploy's failure ends with what the backend said, like the `once` it stopped at,
  rather than only Cloud Run's word that it didn't listen on its port.
