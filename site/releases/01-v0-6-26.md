# 0.6.26

Released 2026-10-08. The compiler and every library move to 0.6.26 together. Nothing
that worked in 0.6.25 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.26) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.26 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.26` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.26` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.26` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.26` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.26` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.26` |
## New

- **Icons on links and toolbars.** A link and a button in a table's or a board's
  toolbar can be drawn as an icon, like a button: `link /:project/boards/:board/workflow
  "Workflow" icon workflow`, `issue::create "New issue" icon add`. The icons are
  `add`, `edit`, `follow`, `following` and `workflow`, and naming another is an error.

## Changed

- A screen laid out in regions keeps its subtitle under its title.
- A section beside the page, in `side`, has a heading a label's size.
- In a list with an order of its own, like by position, rows that tie keep the order
  they were made in, so a new one goes after the others.

## Fixed

- A subtitle in words of its own is shown as them, not read as a page of docs.
