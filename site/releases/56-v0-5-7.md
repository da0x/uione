# 0.5.7

Released 2026-10-05. The compiler and every library move to 0.5.7 together. Nothing
that worked in 0.5.6 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.7) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.7 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.7` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.7` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.7` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.7` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.7` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.7` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.7` |

## New

- **Counting visitors.** `analytics google` in the project block counts a site's
  visitors with Firebase Analytics, once its Firebase project is linked to a Google
  Analytics account of the owner's. It records each screen as it's opened, and asks
  each visitor once whether it may use cookies; until they agree, they're counted
  without them, as Google's consent mode does. See
  [project](/language/reference#project).

## Fixed

- **A view's documents follow its definition.** When the backend starts with a view
  whose definition changed, like one that shows a field more, it rebuilds every
  document of that view, rather than leaving each as it was until something it
  shows changes.
