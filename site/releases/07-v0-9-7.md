# 0.9.7

Released 2026-10-11. The compiler and every library move to 0.9.7 together. A
project checked by another version of the compiler now says so, and an app always
builds with uione's packages at the compiler's own version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.9.7) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.9.7 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.9.7` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.9.7` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.9.7` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.9.7` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.9.7` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.9.7` |

## The right compiler, or a clear error

- **A project names its compiler,** `one "0.9.7"`, and the command line already
  runs that version. Where a compiler can't switch, as in an editor in the browser,
  a project for another version is now one error on that line: it names both
  versions, and says to check it with the project's or to run `one upgrade`.
  Before, it was checked anyway, and anything newer than that compiler looked
  wrong.
- **uione's own packages are always the compiler's version.** An app's
  `components/package.json` can list `@uione/compiler` or `@uione/editor`, but
  the app is built with them at the version of the compiler building it, so a
  listing left behind can't hold them back.
