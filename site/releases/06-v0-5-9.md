# 0.5.9

Released 2026-10-05. The compiler and every library move to 0.5.9 together. Nothing
that worked in 0.5.8 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.9) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.9 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.9` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.9` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.9` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.9` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.9` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.9` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.9` |

## Fixed

- **A yes or no is a box to tick.** A `boolean` field in a form was a text field,
  which sent what was typed; it's a checkbox now, sent as true or false.
- **A diff's removed lines start where its other lines do.** They sat a character
  to the left, padded less than the lines around them.
