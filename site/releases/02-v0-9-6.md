# 0.9.6

Released 2026-10-11. The compiler and every library move to 0.9.6 together. Boards
and tables show how urgent something is without coloring it in, a project's settings
can be one menu over a page for each part, and a form's field can say what it means.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.9.6) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.9.6 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.9.6` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.9.6` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.9.6` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.9.6` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.9.6` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.9.6` |

## Cards that stay out of the way

- **A board's card is the page's own color,** with how urgent it is a thin edge down
  its left side, as the relay front page draws them. Its number reads #12, and the
  people working it are small faces at its foot, apart from its other details: a
  picture, or a first letter, with their name for whoever can't see it.
- **A table's rows and a box of details** show urgency by that edge alone.

## Settings down the side

```one
header /:shop/settings {
	menu {
		link /:shop/settings "General"
		link /:shop/settings/staff "Staff"
	}
}
```

- **A menu in a path's header** goes down the side of every screen under that path,
  with what each screen shows beside it, so a shop's settings are one menu over a
  page for each part.
- **A link can be the settings icon:** `link /:shop/settings "Settings" icon settings`.

## Fields that say what they mean

- **Any field of a form can carry a hint,** shown under it: `open_late "Open late" {
  hint "Orders are taken until midnight" }`.
