# 0.6.27

Released 2026-10-08. The compiler and every library move to 0.6.27 together. Nothing
that worked in 0.6.26 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.27) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.27 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.27` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.27` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.27` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.27` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.27` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.27` |
## New

- **What a page shows is in its path.** A table's tab, a table and board's switch, a
  board's phase on a phone and a page of rows go after the screen's own path, like
  `/neotrac/boards/main/in_progress/board` and `/page/2`, so a link shows exactly
  what's on screen. Only what's typed to find something is a query: `?search=old`.
- **A box that finds across lists.** `find "Search this project" { project_page.issues
  "Issues" link /:project/:issue by number title labels }` finds rows of several lists
  as it's typed in, `#12` by number.
- **Comments in an issue's history, and mentions.** `entity comment history of issue`
  keeps a comment's changes in its issue's history, and `mentioned list of user =
  mentions(body)` holds the people it names with @username, so a person's news can
  pick either: "Ada added a comment to #12".
- **Rows kept by a filter.** A table's `only due <= 2 weeks from now` keeps only the
  rows a filter picks, worked out as it's shown.
- **Trac's priority colors.** `tint by priority` colors a table's rows, a board's
  cards and a details box by a choice, the first red, then yellow, plain, cyan and
  blue, in light and dark.

## Changed

- A required choice, like a priority, offers no empty option in a form.
