# 0.6.19

Released 2026-10-07. The compiler and every library move to 0.6.19 together. Nothing
that worked in 0.6.18 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.19) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.19 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.19` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.19` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.19` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.19` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.19` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.19` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.19` |

## New

- **Breadcrumbs.** A screen whose address goes on from others' shows them as a
  trail above its title, each by its title. `under /:project/boards/:board
  "{issue_page.board_title}"` puts a screen under a page its address doesn't name,
  so an issue's address stays short, like /neotrac/12, while its trail goes through
  its board.
- **The workflow drawn.** `diagram` draws a grid's entries as arrows between boxes,
  forward above and back below; an arrow is pressed to change it, and one is drawn
  from a box to another to add it.
- **Cards.** `cards project_page.boards { ... }` shows rows as large cards, with a
  `tally` of what each holds and up to three `filter`s, links that open it filtered.
  A table or a board opened filtered keeps only the rows its address picks, and says
  so with a way to clear it.
- **A subtitle and icons.** `subtitle "{project_page.summary}"` puts a screen's
  words about itself under its title; `icon edit` draws a button as an icon.
- **History that reads.** A change of what something points at names it by its
  title, a command of its own says from what to what, like moved this from Reported
  to Triaged, and a change no one made says System made it.

## Changed

- `signin google` and `permission signed_in` are the words again; `authentication`
  and `authenticated` are fixed to them, and `one upgrade` does it.
- The app's name isn't in the navigation; its logo links home.

## Fixed

- A hero's background grid no longer widens the page.
