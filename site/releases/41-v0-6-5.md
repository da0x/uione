# 0.6.5

Released 2026-10-06. The compiler and every library move to 0.6.5 together. Nothing
that worked in 0.6.4 changes, so a project for it needs no edit: `one upgrade`
records the new version. A component set of your own, rather than radix, needs four
new components, below.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.5) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.5 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.5` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.5` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.5` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.5` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.5` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.5` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.5` |

## New

- **A title from what the page shows.** `screen "#{issue_page.number}
  {issue_page.title}" /:project/issues/:issue` titles the page, and its tab, with
  the issue's number and title, once they've arrived.
- **Buttons that say what they do.** `issue::create "New issue"` and
  `issue::close "Close issue"` name a button; without a name it's named after its
  command, as before.
- **Buttons only when they apply.** `issue::close when issue_page.status ==
  status::open` shows Close only on an open issue. It compares a view's fields with
  values and choices, joined with `&&` and `||`.
- **Buttons only for whoever may press them.** A command a role grants, like
  closing an issue for a project's maintainers, shows only to the people who hold
  that role in the project the page is about. Someone signed out is asked to sign in
  only for what anyone signed in may do. The roles each person holds are a view of
  their own the build adds, read only by them.
- **Buttons in a row.** Buttons one after another sit side by side.
- **A conversation.** `thread issue_page.comments` shows what people wrote, each
  beside its author's picture and name, with when, and its Markdown rendered.
- **A timeline.** `timeline issue_page.history` says each change in a sentence:
  "Ada created this", "Grace changed status from open to closed".
- **Tabs by a choice.** `table project_page.issues by status` puts the rows in tabs,
  Open and Closed, each with its count.
- **Labels.** A column holding a list of words, like an issue's labels, shows each
  as a chip.

## Fixed

- **Highlighting knows where it is.** A project's settings, like `title`, are
  keywords only in its block, and an entity's rules, like `after`, only in an
  entity, so a column or a field called title or after is a name. A word after a
  dot is never a keyword, a name given a value with `=` is a field, and `change` in
  `each change of` is a type.

## For a component set of your own

`ComponentSet` has four more components: `Thread`, `Timeline`, `Actions` and
`Labels`, and a `Table` may get `tabs`. @uione/radix and the plain set have them
all.
