# 0.6.25

Released 2026-10-08. The compiler and every library move to 0.6.25 together. Nothing
that worked in 0.6.24 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.25) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.25 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.25` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.25` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.25` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.25` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.25` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.25` |
## Changed

- **Long lists read only their newest rows.** A list with a `limit`, ordered by
  `created_at descending` or not at all, like a project's timeline or a person's
  news, asks the database for its newest rows a page at a time, rather than reading
  its whole history each time it's rebuilt. It holds the same rows as before.
- **Indexes, made by the deploy.** `one build` writes the indexes those lists need
  to `firestore.indexes.json`, and the deploy creates each one without waiting for
  it to build, and deletes one no longer needed. Until an index is built, its list
  is read whole, as before.
