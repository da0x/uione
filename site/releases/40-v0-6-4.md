# 0.6.4

Released 2026-10-05. The compiler and every library move to 0.6.4 together. Nothing
that worked in 0.6.3 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.4) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.4 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.4` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.4` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.4` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.4` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.4` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.4` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.4` |

## Fixed

- **A new view has a document for everything already stored.** A view per entity
  added to a project that already had entities, like a view per project added
  after projects were made, had no document for them until each one changed, so
  its screens showed nothing. The backend now builds one for each of them already
  stored when it starts, and every view is rebuilt once when this version first
  starts.
- **A command's button acts on its page's entity.** A button like Close, on an
  issue's page, ran with no issue and failed with "the command needs the id of what
  it acts on"; it now acts on the issue the page's address names.
- **Signing in works while developing.** The app built for the local emulators had
  no auth domain, which Firebase needs before it opens a sign-in window, so signing
  in failed there with auth-domain-config-required.
- **A table's addresses are shorter.** What follows a ? or # isn't shown, and an
  address whose last part won't fit shows its site, like
  console.cloud.google.com/…, with the whole address on hover.
