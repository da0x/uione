# 0.9.4

Released 2026-10-11. The compiler and every library move to 0.9.4 together. A
theme's priority colors keep their hue, light and dark.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.9.4) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.9.4 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.9.4` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.9.4` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.9.4` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.9.4` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.9.4` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.9.4` |

## Priority colors that keep their hue

`tint by priority` colors a row or a card by how urgent it is: the most urgent in
the theme's danger, then its warning, then plain, then its success and its accent.
Each was its color mixed into the surface. A warning is dark, so it reads as text,
and mixed into white it came out tan; on a dark page every tint turned violet.

Each is now its color's hue made vivid, then mixed over the surface without the
surface's own hue, so the high one is a clear orange and a dark page stays warm.
Nothing changes in a project's files.
