# 0.6.9

Released 2026-10-06. The compiler and every library move to 0.6.9 together. Nothing
that worked in 0.6.8 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.9) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.9 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.9` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.9` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.9` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.9` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.9` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.9` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.6.9` |

## New

- **Two columns.** `layout two_columns` after a screen's address lays it out in a
  wide `main` column and a narrow `side` one, beside it on a wide screen and after it
  on a phone; `main { ... }` and `side { ... }` put items in them. The project
  block's `layout` sets it for every screen that doesn't say.
- **A table searched, sorted and paged.** `search title labels`, `sort -number` and
  `page 25` at the top of a table's block give it a search box, an order and pages.
- **Details.** `details issue_page { status "Status"  implementer "Implemented by" }`
  shows a view's values, each beside what it is, leaving out the empty ones.
- **A text only when it applies.** `text "..." when ...`, as buttons have.
- **A person's name through a field.** `implementer = issue.implemented_by.name`.

## For a component set of your own

`ComponentSet` has two more components, `Details` and `Layout`, and a `Table` may
get `search` and `pages`.
