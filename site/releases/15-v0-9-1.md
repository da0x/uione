# 0.9.1

Released 2026-10-11. The compiler and every library move to 0.9.1 together. A field
can hold a file, uploaded from the browser or a program straight to a bucket of the
app's own, and read by whoever may read its record.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.9.1) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.9.1 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.9.1` |

## Files

```one
entity order {
	title     text  required
	proof     file
	pictures  list of file
}
```

- **A file field** holds a file, and `list of file` several, each by its path in
  the app's bucket, whose last part is its name.
- **Uploading goes straight to the bucket.** A form's file box uploads a file as soon
  as it's chosen, showing how far it's come, and the form is sent once every file
  has arrived. The backend only gives somewhere to upload, for ten minutes, at
  `POST /api/files`.
- **A command attaches it** by putting its path in a field, in the command's
  transaction: it has to be the person's own upload, and nobody else's yet.
- **Whoever may read the record may read its files:** anyone when a page of it is
  public, its readers otherwise, people and services alike. Details show each file
  as a link, and a picture of an image.
- **A file taken out of its field, or whose record is deleted, is deleted.** An upload
  never attached goes a day on.
- **A deploy makes the bucket**, `<firebase>-uione-files`, closed to all but the
  backend, with CORS for the site, and keeps it if the stack is ever destroyed.
- **The C++ client** uploads with `upload(path)` and saves with
  `download(path, to)`, with [libember](https://github.com/da0x/libember) 0.1.1.
- **The emulators** run Storage too, on localhost:9199; `tools/emulators/run` builds
  them again for it.

The [reference](/language/reference#files) has it all.
