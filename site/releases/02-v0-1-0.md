# 0.1.0

Released 2026-10-02. The first release of uione: the compiler, and the libraries the
projects it builds stand on.

| Part | Where |
|---|---|
| `one`, the compiler | [github.com/da0x/uione](https://github.com/da0x/uione), built from source |
| `one`, the Go library | `github.com/da0x/uione/one@v0.1.0` |
| `infrastructure`, the Go library | `github.com/da0x/uione/infrastructure@v0.1.0` |
| `@uione/react` | npm, `0.1.0` |
| `@uione/radix` | npm, `0.1.0` |
| `@uione/compiler` | npm, `0.1.0` |
| `@uione/editor` | npm, `0.1.0` |

## What's in it

- Entities, commands and views, with commands as the only writes and every screen
  live.
- Keys and serials: ids made from a project and a number, like `uione-12`.
- Update forms that start from what's stored.
- Lists inside views, ordered and limited, like an issue's comments.
- Roles held within a project and granted by a member entity.
- Public or private projects, with `readers` and `public when` enforced by the
  Firestore rules.
- History: every change to an entity kept, with its before and after.
- Markdown fields, rendered safely.
- Lists of text and people, changed with `add` and `remove` and asked with `has`.
- Names and pictures of the people a view shows.
- GitHub's webhook, with a secret for each project.
- The compiler in the browser, as `@uione/compiler`, with output identical to the
  native compiler's, and `@uione/editor`, which checks `.one` files as you type and
  shows the code each line becomes.
