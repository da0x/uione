# 0.5.11

Released 2026-10-05. The compiler and every library move to 0.5.11 together. Nothing
that worked in 0.5.10 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.11) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.11 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.11` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.11` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.11` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.11` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.11` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.11` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.11` |

## Fixed

- **The editor's menus stay inside the window.** The theme gallery, the fonts and
  the legend open beneath their buttons, moved in so they never spill past the
  window's edge, and above the button when there's more room there. On a phone
  each fills the screen, with an × to close it, and the page beneath holds still.
- **The font and the theme are shown, not named.** The font button is a T, and the
  theme button is a small preview of the theme. Each is named once it's opened, and
  each font in the list is written in itself.
- **A screen opened again starts from what it showed.** `useView` remembers each
  view's last live state, so a header shared by several screens, or a screen
  returned to, no longer goes blank while its view answers again. It's remembered
  for the person signed in at the time, and never shown to someone else.
