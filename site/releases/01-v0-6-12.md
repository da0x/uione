# 0.6.12

Released 2026-10-07. The compiler and every library move to 0.6.12 together. Two
things a project for 0.6.11 may need to change, each of which the checker says
where and offers to fix: an order or a sort with a `-` in front of a key now says
`descending` in words, and an update command that a hand-written component sends
fields to that no form asks for names them with `changes`. `one upgrade` records
the new version.

## New

- **Roles each project defines for itself.** `roles role per project from member`
  makes a project's roles records its people edit, each listing the commands it
  allows, with the roles every project starts with. A member points at one, and
  what it allows now is what they may do, in the backend and on their pages. A form
  for a role ticks the commands it allows; one for a member picks from the
  project's roles. Projects made before get the roles they start with when the
  backend starts.
- **Enums on their own.** `enum status { open "Open"  done "Done" }` names choices
  once, for any field of its type, written `status::open`. An enum on its field can
  be a block too.
- **Order in words.** `order created_at descending`, and `sort number descending` in
  a table; a key is `ascending` unless it says.
- **A theme and square corners.** `theme papercolor` gives a site PaperColor's
  colors, light and dark, and `corners square` squares its panels, buttons, labels
  and pictures.

## Fixed

- **An update changes only what its forms ask for.** Whoever could run an update
  could send it any field, so someone allowed to edit an issue's title could also
  set its status or who approved it. `changes` names fields an update may change
  besides, like those a hand-written component sends.
- A field stored as nothing and written back empty isn't a change, so editing an
  issue no longer adds "set verified by to" to its history; pages leave out the ones
  kept before.

## For a component set of your own

A form field may be `type: "choices"`, several choices ticked and sent as a list. The
page names its theme and corners on the html element, as `data-palette` and
`data-corners`.
