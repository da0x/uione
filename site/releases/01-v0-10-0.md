# 0.10.0

Released 2026-10-12. The compiler and every library move to 0.10.0 together. One
project's screens are now three apps: the web site, a desktop app and a terminal
app, written by `one build` from the same `.one` files.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.10.0) | one command, see [Install](/install) |
| The libraries desktop and terminal apps are built on | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.10.0) | installed with the compiler, in `~/.local/share/uione/0.10.0` |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.10.0 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.10.0` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.10.0` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.10.0` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.10.0` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.10.0` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.10.0` |

## Desktop and terminal apps

```one
project tracker {
	target  web desktop terminal
	signin  google github
}
```

- **`target web desktop terminal`** names the apps `one build` writes:
  `build/web` as before, and `build/desktop` and `build/terminal`, each a CMake
  project of C++26. With none named, it's the web alone, and `--target web` builds
  fewer for one run.
- **Each `.one` file's screens are one C++ file,** the same for both apps. They read
  views live and run commands by name through `one::client`, sign in through the
  browser the first time, and keep the sign-in for the next.
- **The desktop app** is drawn by `one::desktop`, on Wayland and Vulkan, in the
  project's theme: fields with a caret, selection, the clipboard and input methods,
  boards whose cards move along the steps a person's roles may take, and Markdown.
- **The terminal app** is drawn by `one::terminal` in character cells, with the
  same parts, the keys at its foot, and `m` to move a card.
- **Every screen element is drawn by both,** but `component`, a React component
  written by hand, which is the web's alone. A screen using one in a project that
  names a native target is an error, on its line, saying what to do.
- **The installer puts the libraries beside the compiler,** in
  `~/.local/share/uione/<version>`, where a generated app looks for them.
- **`signin google github`** says several ways on one line, as `target` does.
