# 0.7.3

Released 2026-10-09. The compiler and every library move to 0.7.3 together. A site
declares how it looks as a theme, every site follows a reader's system when it asks
for more contrast or less motion, and a site can offer its readers display settings
beside light and dark.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.7.3) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.7.3 check .` |

## New

- **Themes a site declares.** `define theme sea "Sea" from harbor { accent #0b5cad
  dark #8cc4ff ... }` gives ten roles their colors, light and dark, with fonts,
  corners and depth. Everything else a page is drawn with is worked out from them.
  Text that doesn't read on what it sits on, 4.5:1, is a mistake whose fix is the
  nearest color that does. uione's own `harbor` and `papercolor` are written this way.
- **More contrast, from every theme.** When a reader's system asks for more contrast,
  a site draws its theme with text black or white, the rest at 7:1 and lines at 3:1.
  Less motion and Windows' contrast themes are followed too.
- **Display settings for readers.** `accessibility menu` puts a menu beside light and
  dark: more contrast, text up to 200%, comfortable spacing, a legible font, less
  motion, solid panels, underlined links and a thicker focus ring, each kept in the
  reader's browser.
- **WCAG 2.2 AA.** Pages start with Skip to content, focus is never hidden under the
  header, section colors read at 4.5:1, and a form field with an empty label is a
  mistake. [Accessibility](/language/accessibility) says what's checked and what's
  the author's.
- **Code on a darker Nord**, and on a theme's own `ground` when it gives one.

## Moving to it

- `corners square` becomes a theme: `define theme mine "Mine" from papercolor {
  corners 0 }` and `theme mine`. A site's `color` becomes its theme's `accent`.
