# 0.5.5

Released 2026-10-05. The compiler and every library move to 0.5.5 together. Nothing
that worked in 0.5.4 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.5) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.5 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.5` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.5` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.5` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.5` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.5` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.5` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.5` |

## New

- **A person's username, in a view.** Beside their name and picture, a view can show
  the GitHub username of someone who signed in with GitHub, as `member.username`,
  so an app can name and link to people the way GitHub does.

## Fixed

- **A list's type highlights as one type.** In `labels  list of text`, only `list`
  was a type; `of` was a keyword and `text` plain. Now `list`, `of` and what the list
  holds, a built-in type or an entity, are all types, in the editor, on this site,
  and in Vim and VS Code.
