# 0.9.2

Released 2026-10-11. The compiler and every library move to 0.9.2 together. A site
answers at a second domain, like www, and sends people on to its first, so one
project serves both; and a front page can be drawn in one of four designs.

|---|---|---|

## A second domain

```one
project press {
	domain  "press.example" "www.press.example"
}
```

- **One project serves both addresses.** The deploy adds the second to the site's
  hosting, which sends whoever opens it, at any path, to the same path on the first.
- **The DNS records both need** are printed together after the deploy, for the
  registrar.
- **A second domain the same as the first** is an error.
- uione.io does it itself: www.uione.io now sends people to uione.io, where the
  language, the releases and installing are, beside the studio. The installer is at
  `https://uione.io/install.sh`, and the old address still reaches it.

## Front pages in four designs

```one
screen "Press" / landing grid {
	hero "Print that arrives on time." {
		text "Orders, proofs and shipping for a print shop, in one place."
		link "/signin" "Sign in"
	}
	section "You approve every proof" {
		text "Nothing goes to press until you've seen it."
	}
}
```

- **`landing` after a screen's address** draws it as a front page, in one of
  uione's designs: `waveform`, `studio`, `aurora` or `grid`.
- **The design takes the screen's own items:** its hero, with the first link the
  one it's for; its sections of words alone, as what the site offers; and its other
  sections, like one with a form, as what it asks.
- **They're drawn in the theme's colors,** with a gradient from its accent, and
  their motion stops for whoever asks for less.
- **A landing page has no `layout`;** its design lays it out, and saying both is an
  error.

The [reference](/language/reference#screen) has them all.

## Files beside their .one file

- **`code` and `markdown "docs/*.md"`** find their files beside the `.one` file
  that names them, as components and backends do, so a folder of pages can sit in a
  folder of its own. Projects whose `.one` files are at their root see no change.
