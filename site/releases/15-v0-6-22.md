# 0.6.22

Released 2026-10-08. The compiler and every library move to 0.6.22 together. Nothing
that worked in 0.6.21 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.22) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.22 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.22` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.22` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.22` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.22` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.22` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.22` |
## New

- **News for each person.** A view's list can pick through what each row points
  at, like `board.followers has user.id`, and join ways to be picked with `||`, so
  a person's news is every change on the boards they follow or to the issues
  assigned to them. `created_by != user.id` leaves out their own.
- **Timelines that say what they're of.** `timeline news.changes "What's new"`
  puts its title above it, and, like every timeline, isn't shown while it's empty.
- **Filters by time.** A card's filter can keep the rows changed, or due, since or
  before a time counted from when it's opened: `filter "Changed this week"
  updated_at > 7 days ago`, `due <= 2 weeks from now`.
- **Rows that open what they point at.** A table's link can end with a field of its
  rows, like a link's `to`: `table issue_page.links link /:project/:to`.

## Changed

- A list in a person's own view holds only what they may read: a row whose page is
  private to a project they aren't in, or have left, is left out, and comes back
  when they join it or it turns public. Every stored view is rebuilt once, the
  first time the backend starts with this release.
- A namespace written in several files says `at /` in one of them, and every
  file's screens are there. Saying two different places is an error.

## Fixed

- A command named `link::create`, or any `link::…`, reads as a command on a screen,
  not as a link.
- A history says "transferred", "submitted" and the like with their last letter
  doubled.
