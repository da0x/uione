# 0.11.0

Released 2026-10-13. The compiler and every library move to 0.11.0 together. The
desktop and terminal apps draw everything the web does, held to it by a gallery
that uses every control; forms gain sliders and radio buttons; and a theme can be
made at random from a palette, tried on the whole app, and kept.

## New

- **A gallery of every control, on every target.** `examples/gallery` uses every
  screen element, setting and kind of form field there is, built for the web, the
  desktop and the terminal, and its test fails while any target can't draw what it
  uses. What a target can't draw yet is listed in its `gaps`, so a new target, like
  a phone's, starts with everything there and is done when it's empty. It's empty
  now. `tools/gallery` runs it on your machine, signed in, with a room to look at.
- **Sliders.** A number can say its range, `volume  number  from 0 to 100  by 5`:
  the backend keeps it within it, in its steps, and every form asks for it with a
  slider.
- **Radio buttons.** A choice of three or fewer is radio buttons in the desktop and
  terminal apps too, as on the web.
- **Every kind of field is checked for each target,** as screen elements are, so a
  target that can't draw one is an error on its line.
- **Components in C++.** `component welcome_note` finds `components/welcome_note.cpp`
  for the desktop and terminal apps, beside the `.tsx` the web draws: a function of
  the page giving a view, written with the same parts their screens are.
- **Themes from a palette.** `themes` on a screen makes a theme at random from a
  scheme, complementary, analogous, triadic, split complementary or monochrome, and
  draws the whole app in it at once, on the web, the desktop and the terminal. Danger,
  warning and success stay red, amber and green, leaning to the palette, and every
  color reads on what it sits on. Copy gives its `define theme` block, to paste into
  a project. A seed is the same theme everywhere, and `one theme --seed 48213
  --scheme triadic` writes it too.
- **A theme generator on uione.io,** at [/theme-generator](/theme-generator): keep
  the themes you like and apply one to a project of yours, whose theme page opens
  with it, to commit.
- **The terminal apps look like btop:** sections and forms are panels with round
  corners, titled in their border, and while an app runs the terminal draws in its
  theme's colors, put back as it quits, unless `NO_COLOR` is set.
- **Files from the desktop and terminal apps.** A file field is where the file is on
  that machine, typed or pasted, one a line; it's uploaded as the form is sent.
- **The icons `delete` and `archive`** for buttons and links.

## Better

- **The native apps match the hand-written ones:** a terminal lays a screen's
  regions side by side when it's wide enough, rows of buttons go on to the next line,
  tables' columns are as wide as what they hold, a timeline's changes read as
  sentences, details leave out what's empty, and the desktop draws its focus ring
  only once the keyboard is used.
- **Saving a change is quicker:** a change rebuilds only the pages showing it, a
  page reads its parts at once, and what its rows point at is read in one batch.
  Renaming a board with 13 issues went from 3.4 to 1.0 seconds.

## Fixes

- **Numbers from forms.** A form sent a number as text, which the backend refused,
  and a number given as 0 started as its default instead.
