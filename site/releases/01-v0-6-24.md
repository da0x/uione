# 0.6.24

Released 2026-10-08. The compiler and every library move to 0.6.24 together. Nothing
that worked in 0.6.23 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.24) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.24 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.24` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.6.24` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.24` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.24` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.6.24` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.6.24` |
## New

- **What is new, marked.** A timeline's block can say `new since news.seen`, which
  marks the changes made after a value of a view, like when the person last looked,
  and counts them beside its title, and `seen reader::create`, which runs once
  there's something new, to say they've looked. What was new stays marked until
  they leave the page.
- **A count beside the site's name.** `unread news.changes since news.seen`, in the
  project, counts on every page what's new to the person signed in.
- **The earliest of something, in a view.** `seen = first(reader where person ==
  user.id).seen_at` holds a field of the earliest a query picks, or none.
