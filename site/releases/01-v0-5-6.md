# 0.5.6

Released 2026-10-05. The compiler and every library move to 0.5.6 together. Nothing
that worked in 0.5.5 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.6) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.6 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.6` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.6` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.6` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.6` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.6` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.6` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.6` |

## New

- **Color themes for the editor.** Its controls offer the most used themes:
  GitHub, One Dark Pro, Dracula, Catppuccin, Tokyo Night, Nord, PaperColor,
  Solarized, Gruvbox and Monokai, each with its light and dark side where it has
  both, following the page. A theme brings its own background, loads the first time
  it's chosen, and is kept with the reader's font and size; the legend shows its
  colors.
- **Links to other sites say so.** A link that leaves an app opens in a new tab and
  carries the link-external mark, and a table cell holding a web address is such a
  link, shown shortened, rather than its whole text unlinked.
