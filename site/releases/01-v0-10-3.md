# 0.10.3

Released 2026-10-12. The compiler and every library move to 0.10.3 together. A form
that deletes what its page shows goes to a page that's there.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.10.3) | one command, see [Install](/install) |
| The libraries desktop and terminal apps are built on | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.10.3) | installed with the compiler, in `~/.local/share/uione/0.10.3` |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.10.3 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.10.3` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.10.3` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.10.3` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.10.3` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.10.3` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.10.3` |

## Fixes

- **Deleting goes somewhere real.** A form deleting what its address names went to
  the address above it, like `/:project/boards` from `/:project/boards/:board`,
  which may be no page at all, or another screen's, as an issue named boards. It
  now goes to the page its screen is `under`, when it says one, or else the nearest
  page above it: the project's, here. Both the web and the native apps.
