# 0.7.8

Released 2026-10-10. The compiler and every library move to 0.7.8 together. The
display settings, the menu a site gets with `accessibility menu`, are redrawn.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.7.8) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.7.8 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.7.8` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.7.8` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.7.8` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.7.8` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.7.8` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.7.8` |

## Display settings

- **Grouped by what they're for:** reading, color and movement, and finding your
  way.
- **Each choice shows what it does** where a picture says it better: the four text
  sizes as letters at those sizes, both fonts in their own letters, tight and loose
  lines, an underlined link, a thin and a thick focus ring. Contrast, motion and
  transparency are segmented controls.
- **What's chosen** takes the site's accent and corners.
- **The panel says how many settings differ from the system**, beside "Back to my
  system's".
- They're still radio buttons underneath, so keyboards and screen readers use them
  as before, and what's kept in the browser is unchanged.
- Atkinson Hyperlegible now loads from Google Fonts when the panel opens, so its
  card can show it.
