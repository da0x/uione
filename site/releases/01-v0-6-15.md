# 0.6.15

Released 2026-10-07. The compiler and every library move to 0.6.15 together. Nothing
that worked in 0.6.14 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.6.15) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.6.15 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.6.15` |

| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.6.15` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.6.15` |

## New

- **Changes to what's stored, done once.** `once "2026-10-07 workflows" { each
  project { ... } }` is done the first time the backend starts with it, and never
  again, written in the language rather than in Go. Each step is a command's body
  done to every stored entity of a kind, or to those a `where` picks, like `each
  role where name == "developer"`. `phase::triage` is named from the project or
  from what's in it, like an issue, and a once may name what's already stored.
  `one.Once` takes several pieces of work, and `one.Each` is the one a step becomes.
- **A when as a block.** A button's, a text's or a row's button's `when` can be a
  block of conditions, one a line, that all hold:

  ```one
  issue::verify "Verify" when {
  	issue_page.status == status::implemented
  	issue_page.implemented_by != me
  }
  ```
- **Lists over lines.** A long list goes on over lines until its `]`, and may end
  in a comma, and an assignment gives a list field a whole list, like `may =
  [issue::create, issue::move]`.
