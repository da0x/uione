# 0.5.10

Released 2026-10-05. The compiler and every library move to 0.5.10 together. Nothing
that worked in 0.5.9 changes, so a project for it needs no edit: `one upgrade`
records the new version.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.5.10) | one command, see [Install](/install) |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.5.10 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.5.10` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.5.10` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.5.10` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.5.10` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.5.10` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.5.10` |
| `@uione/editor`, the editor for `.one` files | npm | `npm install @uione/editor@0.5.10` |

## New

- **A light theme and a dark theme, each kept.** The editor's look keeps one code
  theme for a light page and one for a dark page. Switching the page's mode
  switches back to the theme chosen for that mode. Only the themes for the current
  mode are offered, so a dark theme is never offered on a light page. A choice
  saved by an earlier version carries over to both modes.
- **Themes chosen from a gallery.** Each theme is shown as a small preview of
  `.one` code in its own colors, with its name underneath. The theme in use is
  outlined.

## Also in this release

0.5.8 and 0.5.9 weren't published to npm, so their changes reach npm with this
release:

- Forms ask a signed-out visitor to sign in before they act.
- A `boolean` field is a checkbox.
- A diff's removed lines line up with its other lines.
