# 0.8.4

Released 2026-10-10. The compiler and every library move to 0.8.4 together. A
table can show a list's records above it as a track, like a project's milestones
as a timeline, and picking one filters the table.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.8.4) | one command, see [Install](/install) |

| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.8.4` |

## A track of milestones above a table

- **`track milestone over board_page.milestones { due }`** in a table's block draws
  the list's records above it as large cards in a row, in the list's order, with an
  arrow from each to the next: a project's milestones, sprints or versions as a
  timeline. Each card shows its title, what the block names, like its date, and
  how many rows it holds.
- **Picking a card** keeps the rows whose `milestone` is it, and picking it again
  shows them all. The one picked is in the path, `/neotrac/boards/main/milestone/beta`,
  so a link shows the same.
- **A board beside the table** takes its track, so switching to the board keeps
  what's picked. A board's own block can say `track` too.
- **On a phone** the cards stay in one row and scroll sideways.

```one
table board_page.issues by phase over board_page.phases link /:project/:issue {
	track milestone over board_page.milestones {
		due
	}
	number "#"
	title
}
```
