# 0.15.2

Released 2026-10-16. The compiler and every library move to 0.15.2 together.
Desktop and terminal apps install and package themselves, with their license, to
hand out as a tarball; a canvas makes cards of the pictures dropped or pasted on
it; markdown is set as a document; a site's header orders its top bar; and an app
started with agents that stop when it quits asks before it does. 0.15.0 and 0.15.1
were tagged on the way here but never published; this is the release of all
they held.

## New

- **Desktop and terminal apps install and package themselves.** `cmake --install`
  puts the program in place as `<project>-desktop` or `<project>-terminal`, with the
  project's `LICENSE` beside it, and a `.desktop` file and icon for the desktop app.
  `cpack` makes a tarball, like `neotrac-desktop-1.0.0-linux-x86_64.tar.gz`, that
  unpacks into `~/.local`. A project without a `LICENSE` beside it, or above it up
  to its repository's root, can't be installed or packaged.
- **Pictures on a canvas.** `paste issue::create into attachments` makes a card of
  each file dropped or pasted on a whiteboard, where it was put, and `picture
  attachments` shows a card's picture. On the web, files are dropped or pasted; in
  the desktop app, Control+V pastes copied files; in the terminal, `p` asks for a
  path.
- **Markdown as a document.** `markdown "docs/*.md" as document` sets pages as a
  sheet to read, in the theme's document font, Libre Caslon Text unless it says
  another, with centered titles, on the web, the desktop and in the terminal.
- **A site's header orders its top bar**: `navigation projects docs about` puts
  those pages first, in that order, the rest after, in every app.
- **The terminal's bars are drawn in blocks**, as btop draws them: a card's tally
  as a meter, and a slider too, in the accent's shades.
- **Cards and find take a view of one list**, as a table does.
- **A section can say `when`**, and is there only while it holds. A workflow's
  `while` works a record only while it holds, keeping it out of every queue and
  refusing a claim otherwise.
- **A track can say `picked last`**, keeping to its newest record until another is
  picked. What a worker says of a record reads as a sentence: its status, where,
  how long ago and its note.
- **`UIONE_LIBRARIES`** builds a project against a checkout's libraries, to try
  them before a release.

## Fixes

- **Quitting stops agents midway, so it asks first.** A terminal or desktop app
  started with `ONE_QUIT_STOPS_AGENTS=1`, as publish starts neotrac's beside its
  agents, asks before it quits while an agent is working on a card, naming each
  card and who holds it. In the terminal, q again quits; on the desktop, closing
  the window again closes it; Esc or Cancel goes back to the board. With nothing
  being worked on, it quits at once, as before.
- **A breadcrumb goes back to a page as it was left.** From an issue opened on a
  board with a milestone picked, the board's crumb returns to that milestone, not
  to the whole board.
- **A step reads what it's making**, so a new project's first board can read the
  project it's made in.
- **A set of one page** is shown as just the page, with no list of one beside it.
- **A screen's `when` compares in order**, as the timeline does, so a view's
  untyped values type-check.
- **A switch remembers what's shown for each page**, like each board, not once for
  them all. Pipelines and a track's cards are dense, a line each.
- **A page's title and subtitle** keep to a reading width.
