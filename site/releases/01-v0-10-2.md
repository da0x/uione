# 0.10.2

Released 2026-10-12. The compiler and every library move to 0.10.2 together. A field
with nothing in it is none, wherever it's asked.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.10.2) | one command, see [Install](/install) |
| The libraries desktop and terminal apps are built on | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.10.2) | installed with the compiler, in `~/.local/share/uione/0.10.2` |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.10.2 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.10.2` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.10.2` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.10.2` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.10.2` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.10.2` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.10.2` |

## Fixes

- **A field holding nothing is none.** A view picking `where closed == none` missed
  every entity whose field was empty text or missing, since the store only matches
  a field that's null, and `!= none` kept them instead. Views and `exists` now ask
  it after reading, so none is a field that's missing, null, empty text or an empty
  list, or a time never set.
- **Screens ask the same.** A button's `when issue_page.closed == none` held only
  for null: the web asks it through `isNone`, from `@uione/react`, and the desktop
  and terminal apps' `same` counts empty text and an empty list as none.
