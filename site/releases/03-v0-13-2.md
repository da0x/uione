# 0.13.2

Released 2026-10-14. The compiler and every library move to 0.13.2 together. A list
switched between a table and a board keeps its toolbar in one place, and a card
arriving where things fail chimes a failure.

| Part | Where | Install |
|---|---|---|
| `one`, the compiler, for Linux and macOS | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.13.2) | one command, see [Install](/install) |
| The libraries desktop and terminal apps are built on | [GitHub releases](https://github.com/da0x/uione/releases/tag/v0.13.2) | installed with the compiler, in `~/.local/share/uione/0.13.2` |
| `one` in a container | `ghcr.io/da0x/uione` | `docker run --rm -v "$PWD:/work" ghcr.io/da0x/uione:0.13.2 check .` |
| The builder, for deploying with nothing installed | `ghcr.io/da0x/uione-builder` | `docker pull ghcr.io/da0x/uione-builder:0.13.2` |
| `one`, the Go library backends are built on | `github.com/da0x/uione/one` | `go get github.com/da0x/uione/one@v0.13.2` |
| `infrastructure`, the Go library deploys are built on | `github.com/da0x/uione/infrastructure` | `go get github.com/da0x/uione/infrastructure@v0.13.2` |
| `@uione/react`, the app's runtime | npm | `npm install @uione/react@0.13.2` |
| `@uione/radix`, the components it draws with | npm | `npm install @uione/radix@0.13.2` |
| `@uione/compiler`, the compiler in WebAssembly | npm | `npm install @uione/compiler@0.13.2` |

## Fixes

- **A table and a board switched between** keep their search box, buttons and the
  switch on a line of their own above them, which stays where it is whichever is
  shown, rather than moving into the table's header when it's picked.
- **A card arriving in a column whose status is failed** chimes the error sound,
  `chime --error` in the desktop and terminal apps and a falling tone on the web,
  rather than the sound for something done.
